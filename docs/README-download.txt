Old Town Walk: a 3D demo of Old Town Fort Collins

A walkable, flyable 3D model of 2 km by 2 km of Old Town Fort Collins, Colorado, built only from open map and
elevation data. Nothing to install.

To run it, unzip this folder and double-click old-town-walk.exe. Keep the tiles folder beside it.

Windows may warn that the program is from an unknown publisher, because it is not code-signed. To run it anyway,
choose "More info" and then "Run anyway".

Controls
  W A S D          walk
  Shift            run
  Mouse or arrows  look
  F                fly, and F again to land
  E or Space       climb while flying
  Q or Ctrl        descend while flying
  [ and ]          time of day
  P                save a screenshot
  H                hide the on-screen label
  Esc              free the mouse (click to take it back); Esc again quits

It needs a graphics card with OpenGL 4.5, which most PCs from the last decade have.
